# Data

## Download

The RealDriveSim-derived dataset is provided in the `data-v1.0` release;
see the [download instructions](../README.md#dataset-download).

## Sources

- [`RealDriveSim-Multi-Style/`](RealDriveSim-Multi-Style/) documents the
  released 20-style image bank and its attribution.
- [`Cityscapes-Multi-Style/`](Cityscapes-Multi-Style/) explains why
  Cityscapes derivatives are not distributed and how authorized users can
  reproduce the style bank locally.

Both directories contain `README.md`, `classes.txt`, and `style_names.txt`.
RealDriveSim also includes source attribution and image/label counts.
The Cityscapes guide describes the corresponding local directory layout.

Generated images and matching labels share a filename stem.
