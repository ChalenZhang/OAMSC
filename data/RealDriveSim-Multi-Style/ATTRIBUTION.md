# RealDriveSim Attribution

This directory contains appearance-transferred derivatives of:

**RealDriveSim: A Realistic Multi-Modal Multi-Task Synthetic Dataset for
Autonomous Driving**

Authors: Arpit Jadon, Haoran Wang, Phillip Thomas, Michael Stanley,
S. Nathaniel Cibik, Rachel Laurat, Omar Maher, Lukas Hoyer, Ozan Unal, and
Dengxin Dai.

Project: <https://realdrivesim.github.io/>

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The OAMSC authors selected 6,000 RGB scenes, generated 20 appearance styles
with an image-to-image model, manually inspected and regenerated failed
outputs, mapped annotations to seven shared road-object classes, and renamed
the public directories using canonical English style names. Retain this
attribution and indicate these modifications when sharing the derivatives.
